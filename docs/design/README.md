# 工作区提示词设置页 · 改版静态稿

在改插件代码前，用这份可交互的静态稿对齐视觉与交互。

## 怎么看

直接用浏览器打开 `settings-page-preview.html`（单文件，无外部依赖、无网络请求）：

- 右上角 **主题**：浅色 / 深色
- 右上角 **状态**：默认 / 编辑中 / 空状态 / 只读
- 可交互：点已配置行展开编辑；右上角「添加工作区」打开原来的选择菜单；开关、保存 / 清除 / 取消、
  菜单选择都能点

## 改版要点

1. **设计语言对齐 dsh-session-sync 设置页**：16/24 页面标题 + 14/22 引言；卡片使用
   `--dsw-alias-settings-card-*` 材质、0.5px 发丝线分块；设置页内容宽 720。
2. **已配置在上、未配置在下**：同一张卡片里，已配置的工作区按名称排在前面；中间用一条带
   「未配置的工作区 · N」的分割行隔开；未配置的工作区只做只读展示（灰色标题 + 路径 + 「未配置」）。
3. **保留原来的添加交互**：右上角仍是「＋ 添加工作区」菜单，菜单里按「标题 / 路径」两行列出
   未配置的工作区；选中后在该行原来的位置插入新配置编辑器（取消则回到未配置区）。
4. **就地编辑**：点已配置行展开灰色编辑器（提示词、字数、保存、清除），保存 / 清除留在编辑器内，
   保存后按名称归位并短暂高亮，不弹窗、不跳页。
5. **开关用标准 Switch**：设置页用官方 `Switch` + 「已开启 / 已关闭」，输入框工具行的自定义 chip 保持不变。
6. **空状态 / 只读**：空状态只在列表上方给一行引导；不可写时顶部 warning banner，写入控件置灰，
   行仍可展开查看。

## 与真实数据的映射

| 静态稿 | 真实数据 |
| --- | --- |
| 已配置行 | `workspaces` 与 `WorkspacePromptsState.entries` 按 cwd 合并后、有 prompt 的项 |
| 提示词预览 / 编辑器 | `entries[].text` |
| 开关 | `entries[].enabled`；写入沿用现有 `toggle(cwd, enabled)` |
| 保存 / 清除 | 现有 `save(cwd, text)` / `clear(cwd)` |
| 添加工作区菜单 | 现有 `workspaces` 与已配置集合的差集 |
| 新配置编辑器 | 现有的 pending row 状态，改为在原位置展开 |
| 未配置行 | 工作区有、`entries` 没有的 cwd；只读展示 |
| 只读 banner | `!state.writable`；`switchSupported === false` 时补「Host 侧仍是升级前版本」的说明 |

## 实现时还要落到代码里的细节

- 排序：已配置、未配置各自按工作区标题排序；未在注册表里的历史 prompt（目录已删除）用目录名兜底，
  仍归入已配置区。
- 开关失败、写入失败：在行内补一行错误文案（静态稿未覆盖错误态）。
- 保存后归位与高亮：约 1.2s 的底色过渡，不改变滚动位置之外的状态。
